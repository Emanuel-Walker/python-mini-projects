# projects/

This folder comes from the upstream community repository:

```text
Python-World/python-mini-projects
```

Each subfolder is an independent community-contributed mini-project.

## How to use this folder

Pick **one** project.

Then:
1. open its local README if present
2. identify its author/credit
3. create an isolated Python environment
4. install only that project's dependencies
5. run only that project

Do not assume all subfolders support the same Python version.

Do not present these community projects as Emanuel Walker's original portfolio work.
