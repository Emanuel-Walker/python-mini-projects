# Repository status

This is a historical fork of the community project:

```text
https://github.com/Python-World/python-mini-projects
```

The individual mini-projects were contributed by many upstream authors.

I keep this fork as older Python learning material.

It is **not** a collection of projects I claim to have personally authored.

## How to read this repo

The main content is under:

```text
projects/
```

Each subfolder is a separate community mini-project.

Different folders may have different dependencies and setup instructions.

There is no single command that proves every project still works on a modern Python installation.
