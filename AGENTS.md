# AGENTS.md

This repository is a historical community fork.

## Rule

Do not treat `projects/` as Emanuel Walker's original portfolio.

Each project may have a different upstream author.

## Working model

One folder under `projects/` = one independent mini-project.

Before editing a project:
1. read its local README
2. identify its dependencies
3. preserve author attribution
4. test only that project

Do not:
- introduce a giant root dependency file
- rewrite all community projects for one Python version
- remove contributor attribution
- publish project-level claims without checking the local files
